# Новости ИСККОН

Собирает новости из источников, переводит их на русский и переделывает
в посты для телеграм-канала [t.me/iskconru](https://t.me/iskconru).

## Как это работает

```
источник (RSS)  →  статья с полным текстом  →  OpenAI  →  пост  →  редактор  →  публикация
```

1. **Сбор.** Парсер читает RSS источника и догружает полный текст каждой статьи
   с её страницы. `iskconnews.org` закрыт Cloudflare, поэтому запросы идут через
   `curl_cffi` с TLS-отпечатком Chrome — иначе сайт отдаёт 403. Вместе с текстом
   забираются фотографии: логотипы и иконки отсеиваются, подпись берётся из
   `figcaption`, `alt` или имени файла — на iskconnews.org её зашивают именно туда.
2. **Переработка.** Модель переводит статью на русский и сжимает в новостной пост.
   Она возвращает только три поля — хэштеги, заголовок и тело; хэштеги проверяются
   по списку канала, а жирный заголовок и подпись собирает сервер. Формат так
   гарантирован, а не оставлен на усмотрение модели. Подписи к фотографиям
   переводятся тем же проходом, одним запросом на статью.
3. **Редактура.** Человек правит текст, видит счётчик символов и предпросмотр,
   отмечает фотографии для поста. Опубликовать пост длиннее 1000 символов
   система не даст.

## Настройка модели

Адрес API, ключ, модель и температура правятся суперадмином в интерфейсе
(«Настройки модели») и применяются сразу, без перезапуска. Значения из `.env`
работают как запасные, пока в базе ничего не задано. Ключ наружу не отдаётся —
в интерфейсе видны только последние символы. Там же кнопка проверки связи
и загрузка списка доступных моделей.

Подойдёт любой сервис с совместимым API: OpenAI, OpenRouter, локальная модель
через Ollama.

## Требования к посту

Заложены в код, а не в инструкцию для редактора:

| Требование | Где обеспечено |
|---|---|
| Не более 1000 символов | Промпт + проверка при публикации (`articles.py`) |
| Заголовок жирным | Сборка поста в `models.py::Post.rendered` |
| Хэштег перед заголовком, из тех, что есть на канале | `ai/hashtags.py` — список собран разбором ~1000 постов канала |
| Подпись в конце | Собирается из настроек источника: «Название» website |
| Стиль постов канала | Системный промпт + глоссарий вайшнавских терминов |
| Только факты из статьи | Явный запрет в промпте, редактор видит оригинал рядом |

## Стек

- **Бэкенд** — FastAPI, SQLAlchemy 2.0 (async), PostgreSQL, Alembic
- **Фронтенд** — Vue 3, TypeScript, Vite, Pinia, vue-router
- **Интерфейс** — дизайн-система [UIUIDS](https://kerse.github.io/UIUIDS/), CSS вендорится в `frontend/src/assets/theme/`
- **Парсинг** — feedparser, curl_cffi, trafilatura
- **ИИ** — OpenAI (адрес API настраивается, подойдёт любой совместимый шлюз)

## Запуск на своей машине

Нужны Docker (для базы), Python 3.13 и Node 20.

```bash
# 1. База
docker compose up -d

# 2. Настройки
cp .env.example .env
# заполнить OPENAI_API_KEY и SECRET_KEY

# 3. Бэкенд
cd backend
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/alembic upgrade head
./.venv/bin/python cli.py createsuperuser
./.venv/bin/python cli.py seed-sources
./.venv/bin/uvicorn app.main:app --port 8001 --reload

# 4. Фронтенд (в другом терминале)
cd frontend
npm install
npm run dev
```

Интерфейс — http://localhost:5173, документация API — http://localhost:8001/docs.

## Роли

- **Суперадминистратор** — заводит и отключает пользователей, правит источники,
  видит журнал действий.
- **Редактор** — работает с новостями: собирает, перерабатывает, правит, публикует.

Первый суперадминистратор создаётся командой `cli.py createsuperuser`.
Система не даёт удалить или разжаловать последнего активного суперадминистратора.

## Источники

Хранятся в базе и добавляются через интерфейс — новый сайт не требует правки кода.
Из коробки заведены два:

| Источник | Откуда | Особенности |
|---|---|---|
| ISKCON News | RSS `iskconnews.org/feed/` | Cloudflare на страницах статей и на файлах картинок |
| Dandavats | Архив `dandavats.com/` | Отдаёт 429 при частых запросах, парсер ходит с паузой |

Источник читается одним из двух способов:

- **RSS** — обычный фид.
- **Помесячный архив** — список «ARCHIVES» на главной странице сайта. Адреса
  месяцев берутся из самого списка, поэтому новый месяц подхватывается сам,
  без правки настроек. Обходятся два последних месяца: на стыке материалы за
  последние числа прошлого могут появиться уже после начала нового.

Архив выбран для Dandavats не от хорошей жизни: в его RSS попадают ссылки на
сторонний блогспот, где вместо статьи стоит проигрыватель, а извлекается
боковая колонка блога — одинаковая у всех таких записей. В архиве лежат
только собственные публикации сайта.

У каждого источника настраивается подпись, которая уходит в последнюю строку поста.

## Служебные команды

```bash
cd backend
./.venv/bin/python cli.py createsuperuser   # завести суперадминистратора
./.venv/bin/python cli.py seed-sources      # добавить источники по умолчанию
./.venv/bin/python cli.py fetch             # обойти активные источники
./.venv/bin/python cli.py backfill-images   # догрузить фото к старым статьям
```
